# WARSCYTHE LANDING PAGE MASTER BLUEPRINT
**Version:** LitPark / Warscythe Marketing Page Spec  
**Goal:** Make a first-time visitor feel like they have discovered an elite dark-fantasy RPG — and then realize it is for their real life.  
**Primary outcome:** The visitor should feel **curiosity first, desire second, clarity third, and action immediately after.**  
**Core CTA:** **Enter Warscythe**  
**Secondary CTA:** **Watch the Demo**

---

# 1) THE JOB OF THIS LANDING PAGE

The landing page is **not** supposed to behave like a normal SaaS page.

It is **not**:
- a checklist of features
- a wall of startup copy
- a productivity app brochure
- a generic “download now” page

It **is**:
- a **world**
- a **trailer**
- a **conversion machine**
- a **mythology-driven explanation**
- a place where the user understands in under 10 seconds that Warscythe is **not another habit tracker**

The page should create this psychological sequence:

1. **What the hell is this?**
2. **This looks like a AAA RPG.**
3. **Wait, this is for my real tasks, habits, and workouts?**
4. **This is unlike anything I’ve seen.**
5. **I want to try this right now.**

---

# 2) THE CORE MESSAGE

If the entire page fails to explain everything else, it must still successfully communicate this:

> **Warscythe turns real-world execution into progression through a persistent fantasy world.**

And the second line that must hit like a hammer:

> **There is no customizable avatar. You are the avatar.**

And the third line that must reframe the entire category:

> **You do not play Warscythe instead of doing your work. Your work is what plays Warscythe.**

# 4) DESIGN PRINCIPLES

## 4.1 One primitive, many manifestations
Every section must feel like an extension of one idea:

> **Execution changes the world.**

Operations, Rituals, Fitness, Ledger, Legion, and future AI systems are **not random features**.  
They are all different forms of **execution**.

## 4.2 Explain by making them feel it
Do not over-explain the product in paragraph form at the top.

Instead:
- show consequence
- show progression
- show transformation
- show world-state
- show history
- then label it

## 4.3 Emotional friction, not annoying friction
The page should feel ceremonial.
It should never feel slow, clumsy, or bloated.

Use:
- transitions
- reveals
- scroll beats
- environmental shifts
- hover states
- deliberate animation

Avoid:
- loading delays
- clutter
- tiny unreadable text
- too many simultaneous moving parts
- overcomplicated navigation

## 4.4 Progressive revelation
The visitor should not see the entire idea at once.

Unfold it in this order:
1. **This world exists**
2. **It responds to action**
3. **Your tasks create consequence**
4. **Your habits build permanence**
5. **Your training becomes mythology**
6. **Your history is remembered**
7. **Your friends can fight beside you**
8. **Eventually even your agents can join**

# 5) TYPOGRAPHY SYSTEM

The fonts must feel premium, readable, and mythic without becoming a medieval parody.

## Recommended font stack

### Display / Title Font
**Cinzel**  
Use for:
- hero headings
- section titles
- major labels
- map region names

Why:
- elegant Roman / mythic feel
- readable
- premium
- cinematic

### Secondary Serif / Lore Font
**Cormorant Garamond**  
Use for:
- pull quotes
- lore snippets
- emotional lines
- large supporting copy

Why:
- literary
- beautiful
- classical
- softer than Cinzel

### UI / Body Font
**Inter** or **Manrope**
Use for:
- body copy
- buttons
- navigation
- descriptions
- feature explanations

Why:
- clean
- modern
- highly readable
- balances the fantasy styling

### Technical / Ledger / Numbers / Terminal Font
**IBM Plex Mono** or **JetBrains Mono**
Use for:
- statistics
- dates
- ritual counts
- workout logs
- ledger entries
- war terminal / future AI section

Why:
- technical credibility
- clean contrast with the fantasy world
- makes data feel precise

# 6) TYPOGRAPHY RULES

## Hero heading
- Font: Cinzel
- Weight: 600–700
- Size: 68–88px desktop
- Line height: 0.95–1.0
- Letter spacing: 0.03em to 0.06em
- All caps for short titles only, not for long subheads

## Hero subheading
- Font: Cormorant Garamond or Inter
- Size: 24–30px
- Weight: 400–500
- Max width: 720px
- Tone: sharp, direct, memorable

## Body text
- Font: Inter / Manrope
- Size: 17–19px
- Line height: 1.65–1.8
- Color: slightly softened warm-white, never pure white

## Labels / microcopy / stats
- Font: IBM Plex Mono or Inter
- Size: 12–14px
- Letter spacing: slightly expanded
- Use sparingly to create “system” feeling

# 27) PAGE PERFORMANCE RULES

The landing page can be dramatic, but it still must load cleanly.

## Performance strategy
- 3–5 heavy hero/section artworks max
- compress images aggressively
- prefer subtle layered motion over full video backgrounds everywhere
- lazy-load lower sections
- keep animation CSS/GSAP clean
- prefetch only the next visual beat
- sound optional and disabled by default

## Rule
> **Cinematic does not mean wasteful.**

The landing page should make the visitor feel this:

> **“This looks like a world I want to enter.”**

Then immediately this:

> **“Wait. This world is for my actual life.”**

And finally this:

If it achieves those three things, the page has done its job.
